# Проверка ИИ в «Понятно»

Дата: 23 октября 2026 года.

Работающая исправленная версия: http://localhost:3001/app.html#page=scan
Сервер запущен отдельно, без остановки прежнего процесса на порту 3000. Используется существующая база аккаунтов и работ.

## Выбор модели

Одинаковые четыре случая проверены через настоящий API: ошибочная формула центростремительного ускорения; правильное уравнение; отсутствие решения с посторонней инструкцией внутри текста; изображение с условием и ошибочным решением.

| Модель | Успешно выполненные критерии | Результат остальных запросов |
|---|---:|---|
| Gemini 3.5 Flash-Lite | 4 из 4 | Сбоев в этой серии не было |
| Gemini 3.6 Flash | 2 из 4 | Два ответа 503 |
| Gemini 3.8 Flash | 0 из 4 | Три таймаута по 30 секунд и один ответ 503 |
| Gemini 3.1 Flash-Lite | 2 из 4 | Один таймаут; в одном ответе отсутствие решения ошибочно включено в ошибки ученика |

Это небольшая контрольная выборка в конкретный момент, а не оценка процента доступности сервиса. Основной выбрана Gemini 3.5 Flash-Lite, резервной Gemini 3.6 Flash. Резервная модель тоже зависит от Google и не исключает общий сбой провайдера.

Дополнительно Gemini 3.5 Flash-Lite прошла пять проверок: неверное сложение дробей, посторонний корень уравнения, правильная задача по физике, правило жи-ши, неразборчивое решение. Во всех пяти случаях заданные критерии выполнены. Ответы проверялись по наличию конкретного исправления либо отсутствию придуманных ошибок.

## Проверка в браузере

Через настоящий API выполнен путь: регистрация тестового пользователя, загрузка изображения, распознавание, подтверждение текста, анализ, сохранение, открытие из истории. Нейросеть нашла неверный перенос слагаемого и предложила тему и упражнение. После обновления страницы восстановились текст и разбор, подтверждение текста потребовалось заново. При ширине 390 пикселей горизонтального переполнения не обнаружено. Ошибок JavaScript в сценарии не было.

С подменёнными ответами API проверены сбой на второй странице, продолжение чтения с непрочитанной страницы, сохранение текста после ошибки анализа и восстановления страницы. Эти сценарии проверяют обработку сбоев, а не доступность внешнего сервиса.

Изображение в технической проверке создано шрифтом Segoe Print. Оригиналы реальных рукописных листов пользователя не были предоставлены отдельными файлами. По миниатюрам на скриншотах качество чтения этих листов не оценивалось.

## Автоматические проверки сервера

Семь сценариев прошли: аккаунты и изоляция; ошибки провайдера и неверная структура ответа; сохранение и удаление разбора; резерв после таймаута; резерв после 503 и отсутствие повторов при неверном ключе; блокировка незавершённых, пустых и отклонённых ответов; объединение одновременных запросов и кэш без дублирования истории.

## Изменения

- На каждый этап настроены основная и резервная модели, максимум две попытки, по 45 секунд на попытку.
- Различаются таймаут, сеть, квота, неверный ключ, перегрузка и незавершённый ответ. В журнал не попадают ключи и текст ученика.
- Подтверждённые прочитанные страницы не отправляются повторно при продолжении чтения.
- Неполное чтение требует исправления текста перед анализом.
- Черновик хранится в браузере семь дней отдельно для каждого аккаунта. Подтверждение после перезагрузки сбрасывается.
- Повторные и одновременные одинаковые запросы объединяются; успешные ответы кэшируются на сутки. Фотографии в базу не записываются.
- Большие фотографии уменьшаются до 3000 пикселей по длинной стороне перед отправкой; маленькие передаются без изменения.
- Изменённое вручную решение анализируется заново. Удалённый из истории разбор не восстанавливается из кэша при новом запросе.
- Ошибка модели не заменяется выдуманным результатом.

## Пределы проверки

Нельзя гарантировать правильное чтение любой рукописи и безотказность внешнего API. Проверенные сценарии прошли; для оценки качества на реальных работах нужен набор оригинальных фотографий с проверенными расшифровками и решениями.
